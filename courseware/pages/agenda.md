# 风控的三次升级

<div class="mt-6 text-lg leading-loose">

1. **专家经验时代**<br/>
   <span class="text-sm opacity-70">信贷员“看人、看店、看流水”</span>

2. **统计模型时代**<br/>
   <span class="text-sm opacity-70">评分卡、逻辑回归，规则 + 公式</span>

3. **大数据 + 机器学习时代**<br/>
   <span class="text-sm opacity-70">海量特征、树模型、图模型、实时决策</span>

4. **大模型 + 智能体时代**<br/>
   <span class="text-sm opacity-70">读文档、做调查、写报告、调用工具</span>
